Vice Cover Studio — a web app that turns your photos and a caption into multi-panel GTA-style poster cover art, exported as a PNG to share. Pick a layout (Poster, Trio, Duo or Quad), load a photo into each panel (your own file or a sample), crop it with zoom and pan, write the caption, pick a colour grade (Sunset, Neon, Golden, Noir) and export in 1080 x 1080, 1080 x 1350 or 1920 x 1080. Static files only, works offline in desktop Chrome; photos never leave your machine. 100% original art — no Rockstar logo, artwork or font. Built by an AI agent for make.fun's “Make GTA 6 Cover Art” bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
